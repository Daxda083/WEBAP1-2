Chapter 4 – Introduction to JSON (exercise sheet A3)

Script: Chapter 4 (sections 4.1 – 4.6)
Folder: /WEBAP/Exercises/ch04/ – one folder ex_xx per exercise (exercise 1 = ex_01, …). The start page of each exercise is index.html; comments marked TODO show where to write your code.

In all exercises, you write a JSON string by hand into the file answer.json of the exercise folder. Check your JSON with the page check.html in this folder (or with jsonlint.com).

Exercise 1 – A string

Folder: ch04/ex_01/   open folder   Files provided: answer.json

Create a JSON-valid string (not an object) that stores your first name.

Exercise 2 – An array

Folder: ch04/ex_02/   open folder   Files provided: answer.json

Create a JSON-valid string that stores the first names of at least 5 classmates in a simple array.

Exercise 3 – An object

Folder: ch04/ex_03/   open folder   Files provided: answer.json

Create a JSON-valid string that stores your first name and age in an object.

Exercise 4 – Different data types

Folder: ch04/ex_04/   open folder   Files provided: answer.json

Create a JSON-valid string that stores your first name, age, height in meters (e.g. 1.85) and whether or not you have seen the latest Star Wars movie in an object.

Exercise 5 – A food object

Folder: ch04/ex_05/   open folder   Files provided: answer.json

Create a JSON-valid string that stores an apple with the following properties in an object:

  • Name: Apple
  • Category: Fruit
  • Weight per serving (in g): 100
  • Number of kilocalories per serving: 64
