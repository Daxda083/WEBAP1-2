Chapter 3 – Reloading content generated with PHP (exercise sheet A2)

Script: Chapter 3 (sections 3.1 – 3.3)
Folder: /WEBAP/Exercises/ch03/ – one folder ex_xx per exercise (exercise 1 = ex_01, …). The start page of each exercise is index.html; comments marked TODO show where to write your code.

Remember: test every PHP script directly in the browser first, e.g. http://localhost:8080/Exercises/ch03/ex_03/getNumbers.php?input=10, before you call it with AJAX.

Exercise 1 – Number sequence

Folder: ch03/ex_01/   open folder   Files provided: getNumbers.php, index.html

The HTML page index.html contains a link and an empty div container.

Create a PHP script getNumbers.php that generates the number sequence [1, 25] as output.

When the user clicks on the link, the number sequence generated with PHP is loaded into the div container.

Exercise 2 – Number sequence in a list

Folder: ch03/ex_02/   open folder   Files provided: README.txt

Create a copy of the previous task in ex_02 and modify your script so that the number sequence is loaded into an unordered list (ul) instead of a div container.

Tip: the PHP script must now generate <li> elements.

Exercise 3 – Number sequence with an input field

Folder: ch03/ex_03/   open folder   Files provided: README.txt

  1. Create a copy of the previous task in ex_03 and add an input field with the ID input.
  2. When the user clicks on the link, the PHP script generates the number sequence [1, <value of input>], which is displayed in the list. The value is read with val() and transmitted to the PHP script via the URL parameter input.
  3. If the parameter is missing, the script generates the numbers 1 to 25 (use ??, section 3.3).

Exercise 4 – List of classes

Folder: ch03/ex_04/   open folder   Files provided: getClassList.php, index.html

  1. index.html contains a button and an empty ul list.
  2. Complete the PHP script getClassList.php. It contains the array $classes.
  3. When the user clicks the button, the values of the array $classes are loaded into the list.

Exercise 5 – Filtering classes

Folder: ch03/ex_05/   open folder   Files provided: README.txt

  1. Create a copy of the previous task in ex_05.
  2. Ignore index.html and AJAX for now and focus on the PHP script. Check it for correctness before you integrate it with AJAX (see note 2).
  3. Send a parameter input (e.g. the value “GI”) to the PHP script via URL. The script reads it into the variable $input and outputs only the classes of $classes that contain the string $input.
  4. Test your PHP script with different values.
  5. Now add an input field to index.html. When the user clicks on the button, the list is filled with all classes containing the text entered by the user.

Note 1: find out about the PHP functions strpos, stripos and str_contains.

Note 2: you can test a PHP script by opening it in the browser and adding the parameters to the URL, e.g. getClassList.php?input=GI.

Exercise 6 – Datalist

Folder: ch03/ex_06/   open folder   Files provided: README.txt

  1. Create a copy of the previous task in ex_06.
  2. Rename your PHP script to getClassDatalist.php.
  3. Read the description of the HTML element <datalist>: w3schools.com/tags/tag_datalist.asp
  4. Modify index.html and getClassDatalist.php so that a datalist is used instead of the list. The datalist is updated while the user is typing (event input) – the button is no longer needed.
