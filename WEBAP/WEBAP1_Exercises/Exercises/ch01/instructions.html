Chapter 1 – jQuery basics

Script: Chapter 1 (sections 1.1 – 1.13)
Folder: /WEBAP/Exercises/ch01/ – one folder ex_xx per exercise (exercise 1 = ex_01, …). The start page of each exercise is index.html; comments marked TODO show where to write your code.

These exercises repeat and practise jQuery: selectors, html(), text(), val(), css(), classes, adding elements, events and animations. No server is needed yet, but open the pages via http://localhost:8080 anyway.

Exercise 1 – Selectors

Folder: ch01/ex_01/   open folder   Files provided: index.html

The page contains the HTML structure of section 1.4 and one button per selector.

  1. When a button is clicked, the elements selected by the selector written on the button get a yellow background (css()). All other elements lose their background.
  2. The button Reset removes all backgrounds.
  3. Before clicking, predict which paragraphs will be selected. Were you right?

Tip: write a function highlight(selector) and call it from every click handler.

Exercise 2 – html(), text() and val()

Folder: ch01/ex_02/   open folder   Files provided: index.html

  1. Insert as HTML: read the value of the input field with val() and insert it into #output with html().
  2. Insert as text: same, but with text().
  3. Show source of the output: read the content of #output with html() and display it in #source with text(), so that the tags are visible.
  4. Test with <b>Hello</b>, <h1>Big</h1> and <button>Click</button>. Explain the difference between both buttons in a comment in your code. Which method should you use for texts entered by users? Why?

Exercise 3 – Retrieving values with val()

Folder: ch01/ex_03/   open folder   Files provided: index.html

  1. When the user clicks Greet me, read both fields with val() and display e.g. Hello Anna Muller! in #output. Remove spaces at the beginning and end with trim().
  2. Clear both fields after the greeting (val("")).
  3. If one of the fields is empty, display Please fill in both fields! in #message, give it the CSS class error (addClass()) and put the cursor into the empty field (focus()). Remove the class again when the input is correct.
  4. Pressing Enter in the field #lastName has the same effect as clicking the button (event keyup, e.key).

Exercise 4 – Calculator – val() returns strings

Folder: ch01/ex_04/   open folder   Files provided: index.html

  1. When the user clicks =, calculate the result of the two numbers with the selected operator and display it in #result.
    Remember: val() always returns a string. What happens with + if you do not convert the values?
  2. If a field is empty or not a number (isNaN()), display Invalid input with the CSS class error.
  3. A division by zero displays Division by zero is not allowed.
  4. For advanced users: remove the button – the result is updated automatically whenever a value or the operator changes (events input and change).

Exercise 5 – val() with all kinds of form elements

Folder: ch01/ex_05/   open folder   Files provided: index.html

  1. When the user clicks Show summary, display all entered values as entries of the list #output (one <li> per field, e.g. Class: 2TPIF). Empty the list first.
    Use val() for text fields, the textarea and the drop-down list, $("input[name='language']:checked").val() for the radio buttons and prop("checked") for the checkbox (display yes or no).
  2. The button Show summary is disabled at the beginning. Enable it (prop("disabled", false)) as soon as the name field is not empty (event input), and disable it again if it becomes empty.
  3. Reset clears all fields, selects English again, empties the list and disables the summary button.

Exercise 6 – To-do list – adding elements and event delegation

Folder: ch01/ex_06/   open folder   Files provided: index.html

  1. Add appends the text of #task as new <li> to #list (append()) and clears the field. Empty tasks are not added. Enter in the field also adds the task.
  2. Clicking on a task marks it as completed: toggle the CSS class done (toggleClass()).
    Attention: the <li> elements do not exist when the page is loaded → use event delegation (section 1.12).
  3. Remove completed tasks removes all li.done (remove()).
  4. #count always shows the number of open tasks (tip: $("#list li").not(".done").length).

Exercise 7 – Repetition – from JavaScript to jQuery

Folder: ch01/ex_07/   open folder   Files provided: index.html

The page index.html works, but it is written in plain JavaScript.

  1. Test the page and read the script carefully.
  2. Rewrite the whole script in jQuery, without changing the behaviour. Use the tables of section 1.11 (properties, methods and events).
  3. Count the lines of both versions. Which one is shorter?

Tip: hover(fIn, fOut), toggleClass(), text(), val(), css(), prop("checked") and toggle() will be useful.

Exercise 8 – FAQ with animations

Folder: ch01/ex_08/   open folder   Files provided: index.html

  1. All answers are hidden at the beginning (CSS). When the user clicks a question, its answer appears or disappears with slideToggle(), and the question gets/loses the class open.
    Tip: the answer is the next element after the question: $(this).next().
  2. Show all / Hide all show or hide all answers with slideDown() / slideUp().
  3. The bar #bar shows the progress: its width is animated (animate()) to number of open answers × 25%.
  4. For advanced users: only one answer may be open at a time.
