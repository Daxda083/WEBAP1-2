Chapter 7 – Advanced techniques in AJAX

Script: Chapter 7 (sections 7.1 – 7.6)
Folder: /WEBAP/Exercises/ch07/ – one folder ex_xx per exercise (exercise 1 = ex_01, …). The start page of each exercise is index.html; comments marked TODO show where to write your code.

These exercises use load() with DATA and CALLBACK, $.ajax(), $.post(), serialize(), error handling and loading indicators. Exercise 3 uses the table tblFirstname (connection in ch07/db.php).

Exercise 1 – Greeting with DATA and CALLBACK

Folder: ch07/ex_01/   open folder   Files provided: greet.php, index.html

Create a page with the input fields firstName and name and a button. Send both values to greet.php using the DATA parameter of load() (section 7.1). The script answers with a greeting that is displayed in #output.

In the callback function, display Loaded successfully or the error message (xhr.status and xhr.statusText) in #status. Test the error message by renaming greet.php temporarily.

Remember: with a DATA object, load() sends a POST request → $_POST.

Exercise 2 – Calculator on the server

Folder: ch07/ex_02/   open folder   Files provided: calc.php, index.html

Create a page with two number fields, a drop-down list with the operators + − × ÷ and a button. calc.php receives the values via $.getJSON() and returns a JSON object such as {"a":12,"b":5,"op":"+","result":17}. For a division by zero or an unknown operator it returns {"error":"Division by zero"}.

Display 12 + 5 = 17 or the error message (CSS class error).

Exercise 3 – Live search with $.ajax()

Folder: ch07/ex_03/   open folder   Files provided: index.html, search.php

  1. While the user is typing into the search field (event input), search.php returns all first names of tblFirstname that contain the typed text as JSON array (LIKE ? with "%" . $text . "%"). Display them in the list, or No results.
  2. Use $.ajax() with .done(), .fail() and .always() (section 7.3). Show #loading during the request and hide it in .always().
  3. In case of an error, display a red message in #status. Test it by changing the URL.
  4. Search only when at least 2 characters were typed; otherwise empty the list.

Exercise 4 – Guestbook with $.post() and serialize()

Folder: ch07/ex_04/   open folder   Files provided: guestbook.php, index.html

  1. The form has the fields name and message. On submit, prevent the page reload and send the form with $.post() and serialize() to guestbook.php (section 7.4).
  2. guestbook.php appends the entry (with date) to the file guestbook.json and returns all entries as JSON array of objects, newest first. Tip: json_decode(file_get_contents(...), true), file_put_contents().
  3. Display the entries without reloading the page, also when the page is opened. Clear the form after sending.
  4. Show #loading while the request is running (test with sleep(1); in PHP).

Note: the web server must be allowed to write into the folder. In the Docker environment run docker exec webap_webserver chown -R www-data /var/www/html/WEBAP if you get a “Permission denied” error.

Exercise 5 – Deleting guestbook entries (for advanced users)

Folder: ch07/ex_05/   open folder   Files provided: README.txt

Copy exercise 4 to ex_05. Every entry gets a unique id (uniqid()). When the user clicks on an entry and confirms, the entry is deleted on the server and the list is updated. Use event delegation (section 1.12) because the entries are added after the page was loaded.
