Chapter 5 – Integrating JSON data with AJAX

Script: Chapter 5 (sections 5.1 – 5.4)
Folder: /WEBAP/Exercises/ch05/ – one folder ex_xx per exercise (exercise 1 = ex_01, …). The start page of each exercise is index.html; comments marked TODO show where to write your code.

All tasks must be solved with the method $.getJSON()!

Exercise 1 – A simple string

Folder: ch05/ex_01/   open folder   Files provided: firstname.json, index.html

Create a JSON file firstname.json that contains your first name. Then create a client script that loads the content of the JSON file at the push of a button and displays it in a div element.

Exercise 2 – An array

Folder: ch05/ex_02/   open folder   Files provided: classmates.json, index.html

Create a JSON file classmates.json that stores the first names of at least 5 classmates in a simple array. Then create a client script that loads the first names at the push of a button and displays them in a ul list. The list must not grow when the button is clicked several times.

Exercise 3 – An object

Folder: ch05/ex_03/   open folder   Files provided: index.html, person.json

The page contains a button and two empty elements with the IDs first and last. Create the server file person.json with the JSON object {"firstName":"John", "lastName":"Doe"}.

At the push of the button, the first name is loaded into first and the last name into last (section 5.3).

Exercise 4 – Hardware table

Folder: ch05/ex_04/   open folder   Files provided: hardware.json, index.html

The file hardware.json contains an array of products. When the user clicks the button, all products are listed in a clean HTML table inside the div container. Prices are displayed with 2 decimals (toFixed(2)). If the file cannot be loaded, display an error message (.fail()).

Exercise 5 – Weather – nested objects (new)

Folder: ch05/ex_05/   open folder   Files provided: index.html, weather.json

The file weather.json contains an object with nested objects and an array. Analyse its structure first.

  1. At the push of the button, display the city in #city and the current weather in #current, e.g. Now: 8 °C, Cloudy, wind 15 km/h (tip: data.current.temperature).
  2. Display the forecast as a table (day, min, max, description) in #forecast.
  3. Rows of days with a maximum of 10 °C or more get the CSS class warm.
  4. For advanced users: display the average maximum temperature of the week below the table.

Exercise 6 – Hardware filter (new)

Folder: ch05/ex_06/   open folder   Files provided: hardware.json, index.html

Use hardware.json of exercise 4.

  1. When the page is loaded, fill the drop-down list #category with all categories that occur in the file – each category only once.
  2. Display the table of all products. When the user selects a category (event change), only the products of this category are displayed. All displays all products again.
  3. #total displays the sum of the prices of the displayed products.

Tip: load the JSON only once and store it in a global variable.
