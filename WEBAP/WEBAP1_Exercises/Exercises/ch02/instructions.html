Chapter 2 – AJAX basics (exercise sheet A1)

Script: Chapter 2 (sections 2.2 – 2.5)
Folder: /WEBAP/Exercises/ch02/ – one folder ex_xx per exercise (exercise 1 = ex_01, …). The start page of each exercise is index.html; comments marked TODO show where to write your code.

All tasks must be solved with the jQuery method load() (except task 4).

Exercise 1 – Loading a text file

Folder: ch02/ex_01/   open folder   Files provided: index.html, name.txt

The file name.txt contains your name. Write an HTML page with a button that, when pressed, reloads and displays the contents of the file name.txt.

Exercise 2 – File name from an input field

Folder: ch02/ex_02/   open folder   Files provided: answer.txt, index.html, welcome.txt

Write an HTML page that contains an input field and a button. When the user clicks the button, the contents of the file <input>.txt should be loaded and displayed on the page (<input> is the content of the input field – use val()).

What happens if the user enters a file name that does not exist on the web server? Write your answer in answer.txt. Look at the Network tab of the developer tools (F12) to explain it.

Exercise 3 – Three links

Folder: ch02/ex_03/   open folder   Files provided: index.html

Create the text files welcome.txt, news.txt and about.txt and fill them with different content spanning several lines.

Write an HTML page with the three links “Welcome”, “News” and “About”. When a link is clicked, the content of the corresponding text file is loaded and displayed.

Tip: the links must not be followed – use e.preventDefault() (section 1.12).

Exercise 4 – Filling a drop-down list (for advanced users)

Folder: ch02/ex_04/   open folder   Files provided: cars.txt, index.html

The text file cars.txt contains car brands in the format brand1;brand2;brand3;...

Create an HTML page with an empty drop-down list and a button. When the user clicks the button, the drop-down list is filled with the car brands.

Tip: $.get("cars.txt", function(data) { ... }) gives you the content as a string; data.split(";") turns it into an array, and append() adds the options (sections 1.9 and 7.3). You can also use XMLHttpRequest (section 2.1).

Exercise 5 – Loading whole web pages

Folder: ch02/ex_05/   open folder   Files provided: answer.txt, index.html, lighthouse.html, trillium.html, css/, gif/, jpg/

Your teacher has given you two web pages (lighthouse.html, trillium.html) with their directories css, gif and jpg. The page index.html already contains the navigation bar (it uses css/style.css).

When you click on “Lighthouse” or “Trillium”, the corresponding page is loaded into the div container with the ID website using AJAX.

When you click on “LPEM”, the Lycée Privé Emile Metz website should be loaded into the div container. Why doesn’t this work? Search the internet for a reason and write your explanation in answer.txt.

Exercise 6 – Loading parts of an HTML file

Complete index.html: it contains the links “Welcome”, “News”, “About” and “Question”. When the user clicks on one of these links, only the content of the corresponding div container in content.html is loaded and displayed (section 2.4: load("content.html #id")).

Complete index.html so that when a letter (e.g. A) is clicked, the corresponding dictionary entries are loaded and displayed in #dictionary. The entries are loaded from the HTML pages a.html, b.html, etc. Load only the entries, not the whole page.

Exercise 9 – Dependent drop-down lists

Folder: ch02/ex_09/   open folder   Files provided: brands.html, cars.html, index.html

Open the files index.html, brands.html and cars.html and analyse their structure. Program the following functionalities in index.html:

  1. When the user clicks the button, the list brands is filled with the car brands of brands.html.
  2. When the user selects a car brand in the list brands (event change, value with val()), all cars of that brand are displayed in the list cars. All cars of all brands are in the file cars.html.
