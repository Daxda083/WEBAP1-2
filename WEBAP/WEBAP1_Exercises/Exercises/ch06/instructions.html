Chapter 6 – Creating JSON data with PHP (exercise sheet A4)

Script: Chapter 6 (sections 6.1 – 6.8)
Folder: /WEBAP/Exercises/ch06/ – one folder ex_xx per exercise (exercise 1 = ex_01, …). The start page of each exercise is index.html; comments marked TODO show where to write your code.

Every PHP script sends the header Content-Type: application/json and outputs its data with json_encode(). Test it in the browser first – you must see valid JSON.

Exercises 7 – 11 use the database. Import sql/webap_sample.sql with phpMyAdmin (http://localhost:8081) if the tables tblFirstname and tblProduct do not exist yet. The connection is prepared in ch06/db.php: include it with require "../db.php"; and use the variable $pdo. Always use prepared statements for values sent by the user.

Exercise 1 – Random numbers

Folder: ch06/ex_01/   open folder   Files provided: getNumbers.php, index.html

Create a PHP script getNumbers.php that creates and outputs a JSON array of 8 random numbers in the range [1, 100] (random_int()).

Create a client script that loads this JSON data at the push of a button and displays it in a ul list.

Exercise 2 – Lottery

Folder: ch06/ex_02/   open folder   Files provided: getLottery.php, index.html

Create a client script that loads the current lottery numbers (without bonus number) from the server at the push of a button and displays them in an appealing format (e.g. as balls, CSS class ball). The numbers are generated by getLottery.php and transmitted as a simple JSON array.

Reminder: lottery numbers are 6 numbers in the range [1, 49].

For advanced users: make sure that no number is drawn twice and sort the numbers.

Exercise 3 – A given number of random numbers

Folder: ch06/ex_03/   open folder   Files provided: getRandom.php, index.html

Create a page with an input field nbr and a button. When the user presses the button, the server script getRandom.php generates as many random numbers in the range [1, 100] as the user has entered. The numbers are transferred as JSON array.

Limit the value to [1, 100] in the PHP script, so that a user cannot ask for a million numbers.

Exercise 4 – Random numbers with min and max

Folder: ch06/ex_04/   open folder   Files provided: README.txt

Extend the previous exercise (copy it to ex_04) with two input fields min and max. The server script returns random numbers in the specified range. If min is greater than max, the script swaps both values.

Exercise 5 – Server information as JSON array

Folder: ch06/ex_05/   open folder   Files provided: getServerInfo.php, index.html

Complete the PHP script getServerInfo.php: it determines the following information with the variable $_SERVER and outputs it as a JSON array:

[ "server name", "server software", "IP address of the server", "document root" ]

The start file index.html is prepared. At the push of the button, the array is loaded and displayed.

Tip: var_dump($_SERVER); shows all available values.

Exercise 6 – Server information as JSON object

Folder: ch06/ex_06/   open folder   Files provided: README.txt

Copy exercise 5 to ex_06. Transfer the values as a single JSON object with one property per piece of information, e.g. {"name": "localhost", "software": "Apache/2.4", ...}, and adapt the client script.

Exercise 7 – First names from the database

Folder: ch06/ex_07/   open folder   Files provided: getFirstnames.php, index.html

Program a page with an input field and a button. When the button is pressed, all first names of the table tblFirstname that begin with the value of the input field are displayed in a list. getFirstnames.php transfers only the first names (no ID, no gender) in a JSON array (section 6.7).

Exercise 8 – All fields as array of objects

Folder: ch06/ex_08/   open folder   Files provided: README.txt

Copy exercise 7 to ex_08. Now all fields of the table – ID, first name and gender – are transferred as JSON objects in a JSON array (PDO::FETCH_ASSOC). Display them in a table. Girls’ names are displayed with the CSS class female, boys’ names with male.

Exercise 9 – Model cars

Folder: ch06/ex_09/   open folder   Files provided: getProducts.php, index.html

The table tblProduct contains model cars of different vendors (columns idProduct, dtName, dtProductLine, dtScale, dtVendor, dtDescription, dtPrice).

Create a PHP script getProducts.php that outputs the names of all model cars as JSON array. Create a client script that loads this information at the push of a button and displays it as an ol list.

Exercise 10 – Model cars of a product line

Folder: ch06/ex_10/   open folder   Files provided: README.txt

Building on the previous exercise, getProducts.php now only returns the names of a specific product line (Motorcycles, Classic Cars, …). The product line is transmitted via the URL parameter line.

The client page contains an input field for the product line and loads the corresponding names at the push of a button.

Exercise 11 – Product lines in a drop-down list

Folder: ch06/ex_11/   open folder   Files provided: README.txt

Modify exercise 10 (copy it to ex_11) so that the user selects the product line in a drop-down list. The drop-down list is filled with AJAX when the page is loaded; the product lines are delivered by getProductLines.php as JSON array (tip: SELECT DISTINCT). When the user selects a product line, the model cars are displayed immediately (event change).
